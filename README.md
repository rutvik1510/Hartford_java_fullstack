# Friends Farmhouse – Booking Webpage

I created a static HTML webpage for Friends Farmhouse that allows users to view information and submit booking details easily.

---

## What I implemented

- Used semantic HTML tags such as header, nav, article, aside, and footer to structure the webpage clearly
- Displayed the farmhouse name as the main heading
- Added a farmhouse image using the img tag
- Controlled the image width using percentage to make it responsive
- Created a navigation bar with links for Home, Booking, and Contact
- Designed a booking form that includes:
  - Name input field
  - Email input field with validation
  - Phone number input field
  - Gender selection dropdown
  - Check-in date field
  - Check-out date field
  - Number of guests field limited between 3 and 12
- Applied HTML form validations using required, min, max, and placeholder attributes
- Added a Book Now submit button
- Integrated a WhatsApp button to send details directly via WhatsApp
- Integrated an Email button using mailto for sending booking details through email
- Styled both buttons using inline CSS
- Embedded a Google Map using iframe to show the location in Hyderabad
- Added a note section reminding users to carry valid ID proof during check-in
- Added a footer section with copyright information

---

## Technologies Used

- HTML5
- Inline CSS
- Google Maps Embed
- WhatsApp and Email Integration
