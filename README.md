Friends Farmhouse – Booking Webpage(Day 1)

I created a static HTML webpage for Friends Farmhouse that allows users to view basic information and submit booking details in a simple and user-friendly way.

What I implemented
	•	HTML Structure
I used proper semantic HTML tags such as header, nav, article, aside, and footer to organize the webpage clearly. I also set the document language and character encoding correctly.
	•	Header Section
I displayed the farmhouse name as the main heading and added a tagline using bold styling with a smaller font size.
	•	Image Display
I added a farmhouse image using the img tag and controlled the image width using percentage to maintain responsiveness.
	•	Navigation Bar
I created a simple navigation menu with links for Home, Booking, and Contact.
	•	Booking Form
I built a booking form that includes required fields such as name, email, phone number, gender, check-in date, check-out date, and number of guests. I used HTML form validation features like required, min, max, and placeholders to ensure correct user input. I also added a Book Now submit button.
	•	Contact Options
I integrated a WhatsApp button that opens a chat using a phone number and added an Email button using the mailto feature. Both buttons were styled using inline CSS.
	•	Location Map
I embedded a Google Map using an iframe to display the location in Hyderabad.
	•	Additional Information
I included a note section to inform users to carry a valid ID proof at the time of check-in.
	•	Footer
I added a footer section with copyright information.

Technologies Used
	•	HTML5
	•	Inline CSS
	•	Google Maps Embed
	•	WhatsApp and Email Integration
