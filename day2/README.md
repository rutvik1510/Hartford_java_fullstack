# Super Cars Grid Layout

This project demonstrates the use of **CSS Grid** to create both:

- **Normal (Desktop-only) grid layout**
- **Responsive grid layout**

### Normal Grid
- Fixed 2-column layout
- Designed for computer screens
- Uses fixed row and image sizes

### Responsive Grid
- Uses `repeat(auto-fit, minmax())`
- Automatically adjusts columns for desktop, tablet, and mobile
- No fixed rows

### Technologies
- HTML
- CSS (Grid)
